# Remanga Reader — мобильное чтение без лишних панелей

Небольшое неофициальное Android-приложение для [remanga.org](https://remanga.org/).

**[Скачать APK последней версии](https://github.com/Regilios/fixFuckRemangaUiUX/releases/latest/download/remanga-reader.apk)** · [Все релизы](https://github.com/Regilios/fixFuckRemangaUiUX/releases)

## Что меняется

- Прокрутка главы вниз плавно скрывает верхнюю панель с главами и профилем и нижнюю панель с кнопками.
- Прокрутка вверх возвращает обе панели. Небольшие случайные движения не вызывают мигания.
- В нижнем ряду появляется кнопка **«На весь экран»**. Она скрывает строку состояния и системную навигацию Android; повторное нажатие возвращает их.
- В полном экране панели сайта продолжают скрываться и появляться при прокрутке. Системным жестом от края можно временно показать панели Android.
- В начале и конце страницы, при открытом меню, диалоге или вводе комментария элементы управления доступны.
- После перехода к другой главе или перерисовки сайта кнопка восстанавливается автоматически.

Изменяется только мобильная разметка чтения `.fresnel-lessThan-md` при ширине страницы меньше 768 CSS px. Каталог, профиль и версия для компьютера остаются интерфейсом самого сайта. При повороте широкого телефона сайт может переключиться на свой компьютерный вариант; верните портретную ориентацию для мобильных панелей.

## Установка и использование

1. На телефоне скачайте `remanga-reader.apk` по ссылке выше. Требуется **Android 8.0+** и актуальный **Android System WebView**.
2. Откройте APK. Если Android запросит разрешение на установку из Chrome, разрешите установку для этого источника.
3. Запустите **Remanga Reader**. Первый запуск открывает указанную исходную главу, последующие — последнюю страницу.
4. Чтобы передать другую страницу из Chrome: **⋮ → Поделиться → Remanga Reader**. Также можно перейти по сайту из самого приложения.
5. В нижнем ряду Remanga нажмите значок четырёх уголков для полного экрана. После скрытия кнопок слегка прокрутите вверх, чтобы вернуть их. Android «Назад» сначала выключает полный экран, затем возвращает предыдущую страницу.

Приложение открывает сайт в собственном Android WebView. Панелей Chrome внутри него нет. В обычном режиме остаются системные панели Android, в полном — скрываются и они. Сам установленный Chrome не меняется: [Chrome Web Store не устанавливает расширения на мобильные устройства](https://support.google.com/chrome_webstore/answer/1698338?hl=ru).

## Аккаунт, данные и ограничения

Вход в Remanga нужно выполнить внутри приложения: cookies Chrome не переносятся. Cookies, настройки сайта и адрес последней страницы хранятся локально в данных приложения. Добавленной аналитики, аккаунтов приложения, собственного сервера и разрешений на файлы, контакты или камеру нет. Сайт продолжает делать собственные сетевые запросы и показывать свою рекламу.

Встроенный браузер открывает только HTTPS-страницы `remanga.org` и `www.remanga.org`. Внешние ссылки передаются обычному браузеру. Нативный интерфейс полного экрана доступен только основному фрейму этих двух адресов. Проверка TLS и Safe Browsing включены.

Авторизация через сторонних провайдеров может не поддерживать WebView; используйте доступный способ входа непосредственно на Remanga. Приложение не обходит платные главы, вход, CAPTCHA или ограничения сайта. При ошибке загрузки есть кнопки повторного запроса и открытия в Chrome.

Селекторы сверены с живой мобильной страницей 1 октября 2026 года. Если Remanga снова изменит DOM, может потребоваться обновление. Автоматические проверки не заменяют проверку полноэкранного режима и входа на реальном телефоне.

## Разработка

- Java 17+, Android SDK 36, Gradle 8.13 (wrapper включён).
- Java + Android WebView; код страницы написан на обычном JavaScript без jQuery.
- AndroidX Activity 1.10.1, Core 1.16.0 и WebKit 1.14.0.

```sh
npm ci
npm test
./gradlew testDebugUnitTest lintDebug assembleDebug
```

На Windows используйте `gradlew.bat`. Путь к SDK задаётся через `ANDROID_HOME` или исключённый из Git `local.properties`. Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`. Для проверки веб-части: `npm run demo`, затем `http://127.0.0.1:4177/manga/example/123` с мобильной шириной окна. Демо не содержит изображения манги и не проверяет Android API.

Основные файлы:

- `app/src/main/assets/reader.js` — выбор панелей, прокрутка, анимация, кнопка.
- `app/src/main/java/org/regilios/remangareader/MainActivity.java` — WebView, безопасный мост, системный полный экран, обработка ссылок.
- `tests/reader.test.cjs` — поведение патча на модели мобильной разметки.
- `.github/workflows/android.yml` — тесты, Android Lint, сборка и выпуск APK по тегу `v*`.

## Подпись и обновления

Релиз подписывается постоянным закрытым ключом. APK следующих версий, подписанные тем же ключом, устанавливаются поверх предыдущей версии с сохранением данных. Для выпуска увеличьте `versionCode` и `versionName` в `app/build.gradle`, обновите `RELEASE_NOTES.md` и отправьте новый тег `v…`.

Workflow использует GitHub Actions secrets `REMANGA_KEYSTORE_BASE64` и `REMANGA_KEYSTORE_PASSWORD`; alias ключа — `remanga-reader`. Ключи и пароли не должны попадать в Git. Локальная резервная копия ключа при первоначальной публикации хранится в исключённой папке `.local/signing/`; сохраните её отдельно в безопасном месте. Потеря ключа лишит возможности обновлять установленный APK той же подписью.

Для локальной release-сборки задайте `REMANGA_KEYSTORE_PATH` и `REMANGA_KEYSTORE_PASSWORD`, затем выполните `./gradlew assembleRelease`. Без этих переменных локальная release-сборка не подписана и не предназначена для установки.
